# Sample questions

These questions are based on the sample documents in `data/documents/`.

## IT support

- How do I report a laptop problem?
- What should I do if I cannot connect to VPN?
- Which issues are treated as urgent?

## Procurement

- When is manager approval needed for a purchase?
- What information should be included in a purchase request?

## Employee handbook

- How many working hours are expected in a normal week?
- What is the process for requesting leave?

Try the same question with different wording and see whether semantic search still finds the right chunk.
